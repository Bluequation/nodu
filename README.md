# Nodu

Repositório do aplicativo de estudos, atualmente com a interface de trabalho **Ritmo 7.1**.

## Versão atual

- `index.html`: aplicativo em arquivo HTML único, pronto para execução no navegador.
- Interface visual inspirada na clareza, organização e aprendizagem interativa do Brilliant, sem reproduzir sua marca ou seus elementos proprietários.
- Os dados do aplicativo são armazenados localmente no navegador (`localStorage`). Use o mesmo navegador e dispositivo para continuar a sessão.
- As funcionalidades principais não dependem de uma API de IA.

## Executar

Abra `index.html` em um navegador moderno. Para publicar como site, configure GitHub Pages para usar a branch `main` e a pasta raiz.

## Desenvolvimento

As próximas alterações devem preservar os dados existentes, o algoritmo FSRS, o caderno de erros, o verticalizador de editais e os planos de estudo. Registre cada etapa no histórico de commits.
